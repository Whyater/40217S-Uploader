Phone setup
  1. Connect the phone to the brain's USB port, not the controller. Use a USB-C OTG adapter with the brain's cable, or a USB-C to micro-USB data cable. Charge-only cables won't work.
  2. Open this page in Chrome. When Chrome asks to allow the device, pick the VEX brain and tap Connect.
  3. For offline use, open Chrome's menu and tap Add to Home screen (or Install app). Open it once online so it can download the robot code.
